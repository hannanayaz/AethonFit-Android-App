# Aethon Fit 💪

Aethon Fit is an Android fitness and workout-tracking application designed to bring workout planning, guided training, exercise discovery, running, progress tracking, and useful Android features into one place.

The app was created from my own ideas and developed with AI assistance during the development, debugging, and problem-solving process.

## ✨ Features

- Personalized weekly workout plans
- Custom workout plans and exercises
- Exercise and movement library
- Interactive muscle and anatomy selection
- Guided workout sessions
- Sets, repetitions, and rest timers
- Time-based exercises
- Running and GPS tracking
- Calorie estimation
- Workout streaks and activity history
- CrossFit Cindy WOD timer
- Light, dark, and system themes
- Android home-screen widgets
- Daily workout reminders and notifications
- Google account selection
- JSON backup and restore
- Spotify workout music integration
- Android-native system integration

## 🛠️ Technologies

- Java
- JavaScript
- HTML
- CSS
- Android SDK
- Android WebView
- AndroidX
- Gradle
- Native Android APIs

## 📱 Download

The latest Android APK is available from the **Releases** section of this repository.

> Aethon Fit is currently distributed as a free Android application.

## 🚀 Installation

1. Open the latest release.
2. Download the Aethon Fit APK.
3. Install the APK on an Android device.
4. Open Aethon Fit and start using the application.

> Android may ask you to allow installation from unknown sources when installing an APK downloaded outside Google Play.

## 🎯 Project Goals

Aethon Fit was created to explore how different fitness, workout-tracking, and Android features can be combined into a single application.

This project has helped me learn and improve my understanding of:

- Android application development
- Hybrid application architecture
- UI/UX design
- Local data storage
- Android APIs
- GPS and location features
- Notifications and widgets
- Debugging and problem solving
- Application build and release workflows

## 🤖 AI-Assisted Development

AI tools were used as development assistants during the project, including for programming guidance, debugging, troubleshooting, and improving implementation.

The overall application idea, feature selection, design direction, testing, and development decisions were driven by my own project work.
